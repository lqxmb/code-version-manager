# 工作空间版本管理

独立的本地 Git 图形版本管理器，可管理任意工作空间。

主要功能：

- 为尚未使用 Git 的目录启用版本管理
- 首次启用时只显示工作空间第一层，勾选目录会递归封装其内容
- 保存后续版本时同样只显示第一层，并记录所选目录内的删除
- 保存版本时自行勾选要封装的文件
- 查看提交历史和版本标签
- 使用 Beyond Compare 比较两个完整版本目录
- 使用 Beyond Compare 比较完整当前工作空间
- 任意选择一个历史版本并下载为 ZIP
- 查看或下载自动生成的版本管理 `CHANGELOG.rst`
- CHANGELOG 标题使用工作空间目录名，每行改动自动输出为 `* 内容`
- 在历史版本状态下阻止误提交

构建安装包：

```bash
./build_deb.sh
```

安装前需要的软件和完整安装步骤请查看 [INSTALL.md](INSTALL.md)。

安装后从应用菜单打开 `工作空间版本管理`。

Changelog for code-version-manager
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

0.2.3 (2026-10-29)
------------------
* 修复发布窗口遗漏已删除的顶层文件和整个目录的问题，默认选中这些删除项并显示“已删除”状态
* 所选删除操作写入 Git 提交和版本标签，避免 GitHub 版本残留旧文件而与 ZIP 封装清单不一致
* 支持仅选择已删除项发布版本；空封装清单导出空 ZIP 和比较目录，避免误导出完整 Git 目录
* 按原始路径处理勾选文件和目录，避免文件名中的通配符匹配其他路径
* 软件版本与 Debian 安装包统一为 0.2.3

0.2.2 (2026-10-29)
------------------
* 将远程同步拆分为“同步本地（以远程为准）”和“同步远程（以本地为准）”两个方向
* 同步前显示当前分支及所有版本标签的本地和远程引用差异，确认后再执行
* 同步本地时先保存未提交修改和未跟踪文件，再覆盖到远程状态；完成后可从弹窗恢复，忽略文件冲突时中止
* 同步远程时原子更新、替换或删除当前分支和版本标签，并以 force-with-lease 防止覆盖检查之后的远程更新
* 覆盖远程前将远程旧引用下载到本地恢复点；其他分支、非版本标签和未跟踪文件不参与同步
* 软件版本与 Debian 安装包统一为 0.2.2

0.2.1 (2026-10-29)
------------------
* 删除本地已同步版本标签后，可从软件中确认删除对应的远程标签并保留提交历史
* 删除本地最新版本及其提交后，仅在远程恰好领先一个带版本标签的提交时提供确认回退
* 远程删除先执行原子 dry-run，再通过 force-with-lease 校验远程分支和标签引用，远程有新更新时拒绝执行
* 在同步按钮中区分普通上传、删除远程标签、回退远程分支和不可安全同步等状态
* 无法识别删除对应关系、远程领先多个提交或权限检查失败时仍禁用按钮，不强制覆盖远程历史
* 软件版本与 Debian 安装包统一为 0.2.1

0.2.0 (2026-10-28)
------------------
* 发布版本仅创建本地提交、标签及版本元数据，移除发布后自动同步选项，旧配置不再触发上传
* 远程上传统一由独立的“同步远程”按钮执行，可一次补齐多个本地版本
* 同步按钮以绿色表示当前分支和版本标签与远程一致，以红色表示存在差异、需要同步
* 未配置远程、无可同步版本、历史版本状态、连接失败或推送预检查失败时禁用同步按钮，并提示原因
* 后台读取实际远程状态，比较分支提交及版本标签，预检查覆盖全部待同步标签；不阻塞本地操作
* 工作空间切换及本地版本变化后重新检查，丢弃过期状态；支持刷新后重试远程检查
* 软件版本与 Debian 安装包统一为 0.2.0

0.1.9 (2026-10-28)
------------------
* 远程同步统一使用 SSH，精简“Git 账号”配置，移除其他登录方式及切换按钮
* 保留 SSH 公钥查看、复制和网页授权，以及“创建远程仓库（网页）”入口
* SSH 公钥窗口支持输入邮箱和可选口令生成 Ed25519 密钥，同名文件自动避让并直接展示公钥
* 根据当前工作空间的 origin 提示 SSH 仓库地址；未配置远程时按目录名提示示例并说明账号需自行填写
* 区分仅保存与保存并验证连接，验证完成后弹窗说明结果，推送超时收纳到高级设置
* 保留发布后自动同步、失败后补同步全部版本、原子推送保护及可配置超时
* 增加 SSH 配置与远程同步回归测试，软件版本与 Debian 安装包统一为 0.1.9

0.1.8 (2026-10-28)
------------------
* 新增 Git 远程仓库配置、发布后自动同步及手动“同步远程”入口
* 同步当前分支完整提交和全部可达版本标签，支持连续离线发布后一次补齐
* 推送失败保留本地提交、标签、清单和 CHANGELOG，不重复创建本地版本
* 分支和标签使用原子推送，不强制覆盖远程历史，同步期间禁止重复操作和切换工作空间
* 增加不上传版本的推送预检查、SSH 公钥查看及网页创建仓库入口
* 推送默认超时为 15 分钟，可按仓库设置 1–60 分钟，连接验证为 120 秒
* 超时清理传输子进程，保留最后输出并支持安全重试，软件与 Debian 包版本统一为 0.1.8

0.1.7 (2026-10-23)

* 下载历史版本时，ZIP 默认文件名增加工作空间名前缀，例如 ``m9_ws_v1.2.0.zip``
* 无版本标签时，下载文件名使用工作空间名和短提交号，仍支持手动修改文件名
* 新增下载文件命名回归测试，覆盖有版本标签和无版本标签的情况
* README 补充 0.1.7 安装包的版本同步、构建和安装命令，软件与 Debian 包版本统一为 0.1.7

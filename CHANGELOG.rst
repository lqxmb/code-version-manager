Changelog for code-version-manager
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

0.1.3 (2026-09-01)
------------------
* 版本历史新增“修改说明”命令，可编辑已发布版本的改动内容
* 保存后同步更新 Git annotated tag、版本列表和 CHANGELOG，不改写提交历史

0.1.2 (2026-09-01)
------------------
* 修复 .git 过滤参数与 Ubuntu Beyond Compare 启动脚本不兼容，导致所有对比功能无法打开的问题

0.1.1 (2026-09-01)
------------------
* “所选版本与当前”直接打开真实工作空间，支持在 Beyond Compare 中修改当前文件
* 历史版本侧保持只读，并隐藏当前工作空间的 .git 目录

0.1.0 (2026-08-31)
------------------
* 最近工作空间菜单新增“清空最近打开…”命令
* 清空前显示确认对话框，避免误操作
* 清空最近列表时保留当前工作空间和其他设置
* 打开位于父级 Git 仓库内的无版本工作空间时，不再自动退回父仓库

0.0.10 (2026-08-31)
-------------------
* 标题栏新增“最近工作空间”菜单，可快速切换已打开过的目录
* 最近记录按使用顺序排列，自动去重、清理失效路径并限制为 10 项
* 兼容旧版 settings.ini，并保留其他配置分区

0.0.9 (2026-08-31)
------------------
* 将界面中的“保存版本”统一改为“发布版本”
* 在窗口标题栏新增“关于”按钮并显示软件版本
* 将 Git 标签、关于窗口和 Debian 软件包版本统一为 0.0.9

0.0.8 (2026-08-31)
------------------
* 将现有 ZIP 快照接入本地 Git 增量版本历史
* 根据 README 整理并补充项目 CHANGELOG
* 忽略构建产物和 Python 缓存，不将生成文件纳入后续版本

0.0.7 (2026-08-31)
------------------
* 将工具元数据从工作空间根目录迁入 .git/code-version-manager
* 将版本清单改为 versions/<版本号>.manifest
* 保存和删除版本时同步维护 Git 私有目录中的清单与 CHANGELOG

0.0.6 (2026-08-31)
------------------
* 将项目从 fetch-version-manager 更名为 code-version-manager
* 同步更名命令、Python 模块、桌面文件、图标和 Debian 安装路径
* Debian 软件包更新为 code-version-manager 2.4.11

0.0.5 (2026-08-30)
------------------
* 支持任意多段数字版本号，并按版本号而非提交日期排序
* 支持删除版本标签，同时保留 Git 提交和工作空间文件
* 在窗口底部显示 Git 增量版本历史占用的磁盘空间

0.0.4 (2026-08-30)
------------------
* 完善 Debian 依赖声明和中文安装说明
* 使用 APT 安装时自动检查并补齐 Python、GTK 和 Git 依赖

0.0.3 (2026-08-30)
------------------
* Beyond Compare 使用独立临时配置并默认折叠下级目录
* CHANGELOG 改为标准 RST 标题和星号列表格式

0.0.2 (2026-08-30)
------------------
* 支持选择任意历史版本与完整当前工作空间比较
* 新增独立安装说明并随 Debian 软件包安装

0.0.1 (2026-08-29)
------------------
* 提供本地 Git 图形版本管理、历史查看、版本比较和 ZIP 下载
* 启用版本管理和保存新版本时按工作空间顶层文件或目录选择
* 支持完整快照比较、自动 CHANGELOG 和历史版本误提交保护
